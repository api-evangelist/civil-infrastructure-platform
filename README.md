# Civil Infrastructure Platform (civil-infrastructure-platform)
The Civil Infrastructure Platform (CIP) is a Linux Foundation project that establishes an open source base layer of industrial-grade software for civil infrastructure systems. It provides a super long-term supported Linux-based platform that can be maintained for more than 10 years for critical infrastructure.
